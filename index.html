A thread through my career

AI

AI has been part of my work since my first year of computer science. It started with search and constraint solving as an undergraduate, continued with classic machine learning in production at Salesforce and a master's degree centred on deep reinforcement learning, and today it means bringing large language models and agents into a production platform.

The Hebrew University · B.Sc.

Search, planning and constraint solving

Back then the field was called classical AI and machine learning. Two projects from that year, both with Ilia Pogrebezky, have stayed with me.

Wedding planner. A guided project with Prof. Jeff Rosenschein that treats guest seating as a constraint satisfaction problem with a cost function: tables of different sizes, must-sit-with and must-not-sit-with rules, hard and soft constraints. We compared backtracking against local search and shipped a working system.

Peg solitaire solver. A game AI for the diamond peg board built on uninformed and informed search with a set of hand-designed heuristics, benchmarked against each other.

Techniques
  • Constraint satisfaction
  • Backtracking
  • Hill climbing
  • Simulated annealing
  • Tabu search
  • A* and IDA*
  • Heuristic design

The Open University of Israel · M.Sc.

Deep reinforcement learning and DQN

My master's degree focused on reinforcement learning and, above all, on Deep Q-Networks, supervised by Dr. Mireille Avigal. The final paper, Deep Reinforcement Learning: Theory, Applications and a Look to the Future, builds the theory up from Markov decision processes, dynamic programming, Monte Carlo and temporal-difference methods to DQN and its successors, then surveys where the field was heading.

The accompanying project is a DQN agent that learns to play Pac-Man from raw pixels, written from scratch in Python.

FundGuard · Software Architect & AI Lead

Large language models and agents

I lead FundGuard's AI work. The first phase was making existing features LLM-ready: data mapping, reconciliation and exception handling that can propose, explain and, with enough confidence, act. The current phase is building agents into the product itself, so that fund accountants and operations teams can run an investment accounting platform in plain language, and so that customers' own agents can work against governed, real-time accounting data.

The architectural principles behind this are public: a single real-time system of record, complete auditability for every decision an agent makes, and open interoperability.

Reading List

Technical books that shaped how I build software, and the one on my desk right now.

Currently reading

Agent Design Patterns

Peter Belcak · Manning, early access

Twenty-plus composable patterns for building AI agents that are reliable, controllable and easy to reason about, each written up as a named problem, solution and trade-offs. I am reading it chapter by chapter as it is released, because a shared vocabulary of patterns is exactly what turning agent prototypes into production systems needs.

Foundations

Computer Networking: A Top-Down Approach

James Kurose & Keith Ross · Pearson

Builds networking from the applications we use down to the wire. It is still the mental model I reach for when something breaks between services.

Craft

Clean Code

Robert C. Martin · Prentice Hall

Not every rule has aged well, but its central idea, that code is read far more often than it is written, shapes how I review code and mentor engineers.

Java & Spring

Spring Boot in Action

Craig Walls · Manning

A practical guide to the conventions behind Spring Boot, the framework under most of the Java services I have built.

Systems & data

Martin Kleppmann · O'Reilly

The clearest map of the trade-offs in storage, replication and stream processing. If I could hand one book to every backend engineer, it would be this one.
